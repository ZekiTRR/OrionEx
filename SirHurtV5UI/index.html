Information & Help
Important information about SirHurt and the UI itself
UI Info
UI specific info
• The UIs settings are saved in SirHurtV5 > webview_data
• If you downgrade versions, please run the SirHurt bootstrapper to ensure SirHurt is running for the correct version as this is not supported natively by the UI itself.
• If fetching fails to load, please restart the UI and if it still fails try restarting your PC.
• This might still be buggy mainly because I havent tested everything, if you find anything or also have suggestions please DM me them.
• If you have more than 10 tabs, you can scroll with the scrollwheel to see them, no slider was added since it looks much cleaner without it.
• Using Roblox Cleaner and Mac Address spoofer in Maintenance is the best way to keep your main safe, never use SirHurt on your main as its never known if SirHurt is detected or not.
SirHurt Info
SirHurt specific info
• If you are crashing on inject or generally, please try restarting your PC.
• Bootstrapper should only be ran when you need to update SirHurt. The UI can update SirHurt but not downgrade SirHurt for older Roblox builds.
• If Roblox is crashing it is suggested to fully uninstall Roblox and maybe SirHurt too.
• For stability Windows 11 24H2+ is highly recommended.
• If you still crash after this, ask for help in the #support channel in the official Discord server.
