# OrionEx

Ремейк [Orion](https://github.com/snooped-xl/Orion) — мультиинтерфейсного скрипт-исполнителя на Avalonia.

Добавлены меню: **Wave**, **SirHurt**, **Script-Ware**, **SirHurt Legacy**, **SirHurt Remake**, **Sentinel**, **JJSploit**, **Wave Legacy**.

> ⚠️ Это лишь MVP — меню могут не соответствовать оригиналу на все 100%.

## Сборка

```
dotnet publish -c Release -p:RuntimeIdentifier=win-x64
```

Готовый exe: `bin/Release/net8.0-windows/win-x64/publish/Orion.exe`

## Контрибьюция

В оригинальном репозитории Orion не указаны лицензия и условия контрибьюции. Этот форк создан для отслеживания изменений и экспериментов.

- Issues и pull requests приветствуются.
- Если переиспользуете код — укажите ссылку на [оригинальный Orion](https://github.com/snooped-xl/Orion).
